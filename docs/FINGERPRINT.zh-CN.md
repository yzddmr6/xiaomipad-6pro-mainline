# 小米平板 6 Pro 指纹使用说明

[English](FINGERPRINT.md)

## 当前状态

FPC1264 指纹是显式安装的可选功能，目前每个 Linux 用户支持一枚指纹。
已记录的 desktop-r3 真机组合通过了正常授权录入、同指匹配、服务重启后
重载匹配、异指拒绝和 GNOME 锁屏解锁，该组合上的自动旋转也正常。
接触位置敏感和解锁卡顿仍存在，尚未测量成功率或触摸至解锁的时延。

项目默认镜像目前不安装这一组件，也不自动启用指纹登录。当前仓库布局和
打包适配是新的候选版本，已通过 CI 构建与打包检查，尚未部署到平板并完成
验收。此前真机结果对应记录中的组件组合，不能扩大为本分支所有镜像都已验收。

## 使用条件与安装

需要此前已验收的支持 boot、为该内核构建的准确 FPC 模块、原厂 FPC/Keymaster
可信应用，以及真实 Gatekeeper/UFS RPMB 提供方。已验证的桌面接口是
libfprint/TOD 1.95.1+tod1 和项目适配后的 fprintd。固件、启动镜像及设备私有
状态分别提供。构建和候选包准备方式见[组件说明](../device/fingerprint/oem/README.md)。

只安装为实际 Linux 账号和支持内核准备的候选包。将归档解压到 root 所有的
目录，以 root 运行其中的 install.py。安装保留密码登录，在真实验收完成前
屏蔽普通 fprintd 服务。密码输入使用独立 PAM 配置，不替换系统密码登录栈。

支持内核目前通过临时 fastboot boot 启动。普通重启会回到已安装内核，指纹
可能不可用。本提交不向真实 boot 分区安装内核；另一内核提交所生成的完整
DTB 尚未通过真机启动验收。

## 首次使用与验证

进入已验收的支持 boot 后，从应用菜单打开“指纹最终验收”。已安装入口使用
限定范围的本地授权；也可以在终端运行：

~~~sh
sudo /usr/local/lib/liuqin-fpc-oem/acceptance.py
~~~

全新的 Linux 账号直接打开上述入口即可：窗口先验证一次 Linux 密码，再通过
正常 Gatekeeper 链创建账号凭据，并用内核内存中的一次性授权继续录入。
已有 handle 的账号直接复用；不要为修复匹配失败重复创建，也不要删除
不确定状态标记来强制重创身份。首次设置及录入会写入安全存储和本地模板。

需要凭据输入时，按正常 Linux 密码提示操作。已有持久模板会直接复用，
不通过重复录入来排查匹配或打包问题。

完整验收依次要求同指匹配、重启服务并重载后同指再次匹配、未录入手指明确
拒绝。全部通过后才启用桌面服务。最后在 GNOME 锁屏后，用已录入手指解锁，
并确认画面和自动旋转。TA 调用成功或编译通过不能代替桌面验收。

已有模板时，单次验证使用：

~~~sh
sudo /usr/local/lib/liuqin-fpc-oem/acceptance.py --verify
~~~

该命令只报告一次匹配结果，不写入完整验收记录，也不完成整套桌面验收。
GNOME 设置页的标准录入暂不支持，因为其 Enroll 接口不提供所需的授权输入。

## 密码变更与恢复

更改 Linux 密码后，运行独立同步入口：

~~~sh
sudo /usr/local/lib/liuqin-fpc-oem/user_credentials.py --sync-password "$USER"
~~~

入口通过 PAM 验证当前 Linux 密码，并以隐藏输入获取此前的指纹凭据密码。
取消或失败保留现有 handle 和模板。桌面密码变更流程尚未自动调用该入口。

需要关闭指纹登录，同时保留凭据和模板时：

~~~sh
sudo /usr/local/lib/liuqin-fpc-oem/acceptance.py --recover
~~~

密码登录仍然可用。恢复入口不会重绑 GENI，也不会重置安全存储。

## 排查与已知限制

- 应用入口不存在时，先核对可选候选包是否已安装；默认镜像不保证包含指纹功能。
- 入口报告内核或模块不匹配、FPC/TEE 节点不可用时，核对候选包对应的准确
  支持 boot 和模块。传感器电压保持 2960000–3008000 微伏。
- 匹配不稳定时，完全抬起手指后调整接触位置。位置敏感仍是已知限制，
  重复录入不是默认恢复步骤。
- GNOME 未解锁或有卡顿时，保留密码登录，并只查看可公开的整数和状态诊断。
  不公开密码、派生输入、handle、HAT、模板、原始图像或私有校准。
- identify 4/12 的特定重试分支、冷启动、休眠恢复和长时间可靠性尚未验收。
  历史 GENI 内存损坏仍未定位，本提交不宣称已修复。

## 组件与来源

内核提交提供 QSEE 通道和 SPI 传感器控制，原厂可信应用负责授权与生物特征
匹配。用户态提交提供真实授权后端、PAM 输入、录入和持久化、TOD 适配器与
fprintd 适配，不使用主机软件指纹匹配器。

依赖版本与原始源码哈希见
[SOURCE_LOCK.json](../device/fingerprint/oem/SOURCE_LOCK.json)。文件级许可证和
[NOTICE](../NOTICE) 保留原始署名及条款。/dev/fpc1020 和 fpc,fpc1020 是保留的
设备 ABI 名称；当前经过验证的硬件范围是本平板的 FPC1264。
